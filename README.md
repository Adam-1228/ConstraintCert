# ConstraintCert

Reproduction artifact for **ConstraintCert: Auditing Metadata-Filter Translation and Execution Across Five Backends**, by CHI YONG SEONG (Independent Researcher).

[Download the frozen reproduction package](https://github.com/Adam-1228/ConstraintCert/releases/tag/v1.0.0-paper-artifact).

The archive contains source, actual raw experiment evidence, corpus source snapshots, version-audit dependencies, component licenses, instructions and a complete SHA-256 inventory. It reports **17,600 observed parent cases** and explicitly retains the original 20,000 allocation and post-results withdrawal of 2,400 unexecuted H6 human/parser cases with zero empirical credit.

H2 did not meet its global precision requirement. H3 supports the restricted matched-safety baseline comparison, with the recall gap entirely in baseline-unsupported cases. H1/H4/H5 and version conclusions retain their evidence failures and inconclusive decisions. No production certification, human parser accuracy, independent external reproduction, or accepted/submitted paper status is claimed.

## Use

Download and extract `ConstraintCert-reproduction-20260927-v1.zip`, verify its adjacent SHA-256 file, then follow the archive's `README.md`. `FILES.json` binds every payload file. Start with the two standard-library analysis checks; database reruns are separate and require the frozen dependencies and environment contracts.

The archive is about 221 MB (1.95 GB uncompressed payload). Historical source and result bytes are preserved. This does not promise turnkey execution of all original Windows-specific launchers on arbitrary machines.
